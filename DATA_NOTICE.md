# Data Notice

This repository does not redistribute OASIS MRI images, derived patient data, trained model weights, project-specific writing, figures, result tables, or private research materials.

Users must obtain OASIS / Learn2Reg data from the official public data providers and comply with the applicable data-use terms. The scripts here only describe reproducible loading, splitting, and synthetic contrast generation utilities.

Do not commit local data files to this repository. The `.gitignore` file excludes common imaging, archive, checkpoint, and generated-data formats.
